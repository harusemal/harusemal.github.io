# 하루세말 (Harusemal)

**하루 세 가지 우리말 표현으로 키우는 문해력 | 3 Korean expressions a day**

- 홈페이지: https://harusemal.kr (연결 예정)
- 대상: 중·고등학생부터 성인까지, 그리고 기초를 뗀 한국어 학습자

## 구성
- `index.html` 첫 화면(오늘의 세 표현, 내 표현장, 복습 카드, 퀴즈)
- `data/expressions.js` 표현 데이터(공개일 `release` 기준으로 표시)
- `assets/` 화면 꾸밈(CSS)과 동작(JS)

학습 기록(내 표현장, 복습 진도)은 서버에 저장하지 않고 **각 사용자의 브라우저에만** 저장합니다.
